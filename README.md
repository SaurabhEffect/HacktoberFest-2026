# Hacktoberfest 2026

I keep my Hacktoberfest 2026 projects in this repository. Each project has its
own folder and README with setup instructions.

## Projects

- [NoFumble](./NoFumble/README.md) - local-first cash-flow forecasting and
  expense checks.
- [Ghosted](./ghosted/README.md) - a local-first review queue that finds
  unanswered GitHub issues and drafts replies without posting them.
- [The Won't-Do List](./wont-do-list/README.md) - a local-first app that sorts
  tasks into what to do now, later, or let go.
- [This Week Outside](./this-week-outside/README.md) - a hyperlocal field guide
  for things to look for outdoors this week.
- [Hinglish Reel Captioner](./hinglish-reel-captioner/README.md) - local Roman
  Hinglish captions for reels and voice notes.
